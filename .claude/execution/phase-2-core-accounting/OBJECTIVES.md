# Phase 2: Core Accounting + Bokføringsloven Compliance

## Objective
Implement the core accounting functionality that satisfies Norwegian bookkeeping law.

## Deliverables

### 1. Bilag (Document) Management
- Upload interface (drag-drop, email forwarding)
- OCR processing pipeline
- Automatic categorization
- Manual review/approval workflow
- Sequential numbering system
- PDF/A conversion

### 2. Posting Workflow
- Create postings from bilag
- Double-entry validation
- Account selection with NS 4102
- VAT code assignment
- Approval states

### 3. Hovedbok (General Ledger)
- Account listing with balances
- Transaction drill-down
- Period filtering
- Export functionality

### 4. Balance Sheet & Income Statement
- Real-time balanse
- Resultatregnskap
- Period comparison
- Trend indicators
- Ciri insights

### 5. MVA (VAT) Management
- VAT calculation per period
- MVA-melding preview
- Altinn submission preparation
- Termin tracking (2-month periods)

### 6. SAF-T Export
- Version 1.30 compliance
- Næringsspesifikasjon mapping
- Validation before export
- One-click generation

## Success Criteria
- [ ] Bilag can be uploaded and auto-categorized
- [ ] Postings maintain two-way audit trail
- [ ] Balance sheet always balances
- [ ] SAF-T export passes validation
- [ ] MVA calculation is accurate

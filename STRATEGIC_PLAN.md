### The Psychology of Optimal Pricing

#### Key Principles

1. **Anchoring against accountant, not software**
   - Customer thinks: "15,000-50,000 kr/år for regnskapsfører" vs "2,988 kr/år for Ciri"
   - Savings: 12,000-47,000 kr/år = **80-94% cheaper**
   - This is the no-brainer calculation

2. **Price below market leader (Fiken at 209 kr)**
   - Fiken is the "default choice" for small Norwegian businesses
   - Pricing below creates instant competitive advantage
   - But not too low (signals quality concerns)

3. **Freemium funnel**
   - Free tier captures price-sensitive users
   - Usage limits drive upgrades naturally
   - Every free user is a potential paid conversion

4. **Psychological price points**
   - 149 kr feels significantly cheaper than 209 kr (29% less)
   - 249 kr feels fair for "premium" features
   - 499 kr feels premium but still <500 psychological barrier

class CiriCostOptimizer:

    # 1. Semantic response caching
    async def get_cached_response(self, query: str, company_id: str):
        """
        Cache AI responses for similar questions.
        Uses embedding similarity, not exact match.

        embedding = await self.embed(query)
        cached = await self.find_similar(embedding, threshold=0.95)
        if cached:
            return cached.response  # No API call needed
        return None

    def select_model(self, task_complexity: str):
        """

            return "claude-3-5-sonnet"  # Balanced

    async def batch_document_analysis(self, documents: list):
        """
        Batch multiple documents into single API call.
        """
        combined_prompt = self.combine_for_batch(documents)
        response = await self.call_api(combined_prompt)
        return self.split_response(response)

    # 4. Prefetching
